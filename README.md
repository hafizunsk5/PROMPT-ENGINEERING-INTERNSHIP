# Prompt Engineering Internship



This repository contains the tasks I completed during my Prompt Engineering Internship.



The tasks helped me learn how to write better prompts, create different types of content, automate simple tasks using prompts, and design an interactive AI assistant.



## Internship Tasks



### Task 01 - Writing Better Prompts



In this task, I worked on improving vague prompts by adding clear instructions about the audience, required content, structure, and response length.



I compared the responses from vague and improved prompts and analyzed how specific instructions affected the output.

### Task 02 - Prompting for Creativity



In this task, I created advertisements for an eco-friendly water bottle using different prompting styles.



I tried a basic prompt and few-shot prompts with different tones, including a youthful style and a premium style. I then compared the results.



**Files:**



- [SCT_PE_2.md](SCT_PE_2.md)

### Task 03 - Prompting for Task Automation



In this task, I created a reusable prompt to analyze customer feedback and convert it into structured JSON data.



I used examples and fixed output values for sentiment, category, priority, issue, and action required. I also tested and improved the prompt to make the results more consistent.



**Files:**



- [SCT_PE_3.md](SCT_PE_3.md)

### Task 04 - Simulating an Assistant



In this task, I designed a CSE internship interview assistant that conducts a short mock interview.



The assistant asks questions one at a time, uses the candidate's previous answers to decide the next question, adjusts the difficulty, and gives a final evaluation.
